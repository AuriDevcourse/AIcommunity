## Demos

### Auri — Automated Visual Creation Tool for TechBBQ
**Stack/tools used:** Windsurf, GitHub, .md files
**What & why:**
- Previous project: Signature generator for TechBBQ (MarketingKit)
- New project: Automated visual creation tool — attendees can make their own shareable card
**How it was built:**
- Splitting the project into days
- Asking AI to create a daily summary in a file, then feeding it to a new chat the next day
- New chat gets updated on progress and what still needs to be done
- Using 2 AI tools to cross-check logic and catch hallucinations
- .md files structure: Context, Requirements, Technology, Process, Prompt, Framework
**Key takeaway:** Start a random chat with AI → describe what's needed, requirements, suggestions → tell it to ask questions → have it create .md files for continuity across sessions

### Ignas — Make.com Automation for Content Creation
**Stack/tools used:** Make.com, Dropbox, ChatGPT
**What & why:** Automate social media content — image recognition, captions, scheduling
**Demo notes:**
- Make.com couldn't connect to Google Drive, used Dropbox instead
- Had real images of vases in Dropbox, connected to ChatGPT for caption generation

- Future: Telegram notifications to approve/reject scheduled posts before publishing
